# Hi, I'm Volodymyr

I'm a Senior SRE on GitLab's release management team. I help run the monthly release trains, own production upgrades, and write ChatOps commands and Ruby tooling that replace manual release steps.

Before GitLab I spent five years at Soft Cannery, where I moved AWS and Azure infrastructure to Terraform, built GitOps pipelines and set up the team's first monitoring. Before that I did QA automation, and before that I led a 15-person IT team at PrivatBank. That's 10+ years in infrastructure. Now I'm growing into MLOps.

I live in Vancouver, BC and I'm open to SRE, DevOps and MLOps roles in Canada.
